# Professional Profile Website

A modern, responsive personal profile website showcasing professional experience, skills, and projects. Built with HTML5, CSS3, and JavaScript.

## Features

- 🎨 Modern and clean design
- 🌓 Dark/Light mode toggle
- 📱 Fully responsive layout
- ⚡ Smooth scrolling navigation
- 🎭 Animated sections
- 📝 Dynamic content loading
- 📬 Contact form
- 🔗 Social media integration

## Technologies Used

- HTML5
- CSS3 (with CSS Variables for theming)
- JavaScript (ES6+)
- Font Awesome Icons
- Google Fonts (Inter)

## Project Structure

```
.
├── index.html          # Main HTML file
├── styles/
│   └── main.css       # Main stylesheet
├── scripts/
│   └── main.js        # Main JavaScript file
└── assets/            # Images and other media files
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/anil14349/anil14349.github.io.git
   ```

2. Navigate to the project directory:

   ```bash
   cd anil14349.github.io
   ```

3. Open `index.html` in your web browser or use a local server.

## Customization

### Content

- Update the content in `index.html`
- Modify experience data in `scripts/main.js`
- Update project information in `scripts/main.js`

### Styling

- Edit CSS variables in `styles/main.css` to change colors and theme
- Modify media queries for responsive design
- Update animations and transitions

### Contact Form

- Add your form submission logic in `scripts/main.js`
- Update the form endpoint in the JavaScript file

## Deployment

This website is designed to be hosted on GitHub Pages. To deploy:

1. Push your changes to the main branch
2. Go to repository Settings > Pages
3. Select the main branch as the source
4. Save the changes

Your site will be available at `https://anil14349.github.io/`
